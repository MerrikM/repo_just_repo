# Telnet Client

Простой telnet-клиент на Go.

## Использование

```bash
go run telnet.go [--timeout=10s] host port
````

* `--timeout` — таймаут подключения (по умолчанию 10 секунд).
* `host` — адрес сервера.
* `port` — порт сервера.

## Возможности

* Подключение к TCP-серверу.
* Ввод с клавиатуры отправляется в сокет.
* Ответы сервера печатаются в stdout.
* `Ctrl+D` — завершение работы клиента.
* `Ctrl+C` — корректное завершение по сигналу.

## Пример

Для запуска echo сервера (порт по умолчанию 8080):
```bash
go run echo.go
```
Для запуска telnet клиента:
```bash
go run telnet.go localhost 8080
```

Подключение к SMTP-серверу (для теста):
```bash
go run telnet.go smtp.gmail.com 25
```
